# Week 3 – Password Cracking (Dictionary Attack)

## Introduction

As part of my Cybersecurity Internship at Networkwalks Academy, I completed a practical project on Password Cracking using the Dictionary Attack approach.

The objective of this practical was to understand how dictionary-based password attacks work and how password recovery can be performed in a controlled lab environment.

## Practical Tasks

1. Performed PDF password cracking using a dictionary attack.
2. Used the Networkwalks Password Cracker Lab.
3. Worked with John the Ripper (JtR) and Johnny GUI.
4. Identified passwords through dictionary-based attempts.
5. Verified successful password recovery.
6. Captured the challenge flags provided during the practical.

## Tools Used

- John the Ripper (JtR)
- Johnny GUI
- Networkwalks Password Cracker Lab
- PDF Files

## Practical Results

- Successfully recovered PDF passwords using dictionary attacks.
- Verified password-cracking results through Johnny GUI.
- Successfully captured multiple challenge flags.
- Gained practical understanding of password hashes and dictionary-based password recovery.
